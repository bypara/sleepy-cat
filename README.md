# Домен занят. Котом.

Минималистичная страница-заглушка: чёрный фон, спящий кот и 32 реплики во всплывающих облачках.

Кот реагирует на клики и движение мыши без нажатия. На телефоне его можно потрогать нажатием. Анимации учитывают системную настройку уменьшения движения.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

Для локального сервера:

```bash
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

## Файлы

- `index.html` — страница, стили и интерактивность.
- `cat.webp` — изображение кота.

Тексты находятся в массивах `excuses` и `petReplies` внутри `index.html`.
